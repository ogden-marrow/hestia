# Hestia: what we are building and why

These are the forces behind every decision. When a change does not serve one of them, it does not belong.

1. **Your computer, as code.** The operating system setup, applications, documents and machines live in one private git repository. Nothing about how your computer is set up is lost when it is.
2. **It organises itself, and asks only when unsure.** A stream of everything that arrives; a classifier files it; each morning one screen says what it did and asks a few questions. You never hunt for a folder. (Lifestreams: Freeman and Gelernter.)
3. **Files and folders are one thing.** Organisation is derived from domains you define (documents, pictures, videos, music, applications, games, software, data, machines). Domains are editable and teach the classifier.
4. **Every machine is known.** Each machine has a fingerprint; applications are separated by OS and version; a new computer can be rebuilt from the repository.
5. **Private by construction.** Your data never leaves your computer unencrypted and unreviewed. Sensitive paths are never read. Pushes go only to a private repository, and stop if anything looks like a secret.
6. **Never destructive.** Hestia moves and copies; it never deletes. Anything it did can be inspected and undone.
7. **Lean.** One way to do each thing. No legacy code, no duplicate screens.
8. **It feels like a good native app.** Flat, classic-Mac warmth; light, dark and auto; every control shows what it is doing; nothing freezes.
9. **Hestia is a separate public project with no personal data.** Your own setup lives in your private home repository, which tracks Hestia as a submodule.

## What "done" means
A stranger installs it, follows the first-run flow, and within a day has a backed-up, organised computer, without reading source code or editing a file by hand.
